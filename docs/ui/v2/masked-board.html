匿名遮蔽态：390 与 320 两个真实视口

界面稿 09 / 两个 iframe 各自是独立视口，媒体查询真实生效；320 下无横向滚动，底部安全区不压内容。

390 × 1180主流手机

320 × 1180最窄支持宽度

这一稿要说明什么 09

  1. 遮蔽不是 CSS 遮挡真实号码与完整描述根本不进匿名响应；占位块是唯一渲染内容，查看源码和读屏都拿不到。
  2. 占位样式统一虚线 + 浅底 + 「登录后可查看」，内联（地点）与块级（描述/联系方式）两种尺寸，语义相同。
  3. 登录 CTA 带回路「去登录」跳 /login?redirect=当前路径；只接受站内相对路径，防开放重定向。
  4. 390 / 320 都可用320 下品牌文字收起、标题换行、占位块满宽；页面无横向滚动，底部安全区留白。

390/320 是 iframe 的真实视口宽度，不是把 1280 稿缩小的假移动端。生产实现时用 Chrome DevTools 的 320×568 复核一次。
