错误态 共同规则

  1. 不泄露账号是否存在只给「学号或密码不正确」；不区分「学号不存在」「密码错误」。
  2. 保留学号、清空密码焦点落到密码框；页级 role="alert" 只播报一次。
  3. 字段为空是客户端校验逐字段报错 + 顶部摘要，焦点落到第一个空字段。

锁定态 B2 策略

  1. 阈值由后端定UI 不写死「5 次」；只展示 B2 返回的剩余秒数与锁定文案。
  2. 倒计时可见视觉 09:58；读屏只在开始与结束时播报，不每秒打断。
  3. 仍可行动文案给出「联系课程助教」，不是死路。

无障碍 登录页

  1. autocomplete学号 username、密码 current-password；学号 inputmode=numeric。
  2. 显示密码真实按钮、aria-pressed，键盘可达；不改变字段值。
  3. 焦点可见错误态密码框的焦点环用 --ring；锁定态控件 disabled，不伪装成可编辑。
