这一稿要说明什么 08

  1. 提示必须紧邻「自行填写，请自行核实」在输入框下方第一行，不折叠、不放进 tooltip；后面跟一句「不发送短信验证码」。
  2. 只做格式校验11 位、以 1 开头；错误文案「请输入 11 位手机号（示例：138 0000 0000）」，不承诺号码真实。
  3. 不存到用户表号码只挂在启事上；t_user 不存手机号。UI 不提供「保存为我的手机号」。
  4. 与已知限制一致发布页出现「不会自动下架」与「号码可见规则」；完整三条在 /my 的使用说明区块。

字段命名依赖 A1：手机号列名、是否与「其他联系方式」并存，以 A1 契约为准；本稿只锁定 UI 标签、提示文案与校验规则。
