这一稿要说明什么 02 / 06

  1. 三种状态各有确定文案分析中 / 已出结果 / 已降级。状态行同时给文字与形状（转圈、实心点、警示色点），不只靠颜色。
  2. 条数 = 配对数「3 条可能相关」是 3 个 1:1 配对，不是 3 条记录被锁定；每条独立，处理一条不影响其余。
  3. 已降级不是失败结果仍然可用，只是引擎换成 LOCAL_KEYWORD；页面必须说明「可能不够准」，并给「重试分析」。
  4. 关闭只能本人关闭启事是发布者操作；没有定时下架、没有匹配成功自动关闭。关闭不动已有配对。

布局：≥900px 时「记录信息 / 匹配摘要」两列；窄屏改为上下堆叠，匹配摘要顶部分隔线，320px 无横向滚动。记录行内不嵌套第二张卡片，只用分隔线分组。
