这一稿要说明什么 03 / 06

  1. 未读不是只有红点红点 + 标题加粗 + 行浅底，三通道；读屏用 aria-label 读「未读：…」，不依赖颜色。
  2. 通知必须能行动每条都链到对应启事 / 配对；「全部标为已读」在未读为 0 时禁用，并使用 aria-disabled。
  3. 文案带上下文说清楚是哪条启事、哪个配对、发生了什么；不写「系统通知」这种无法行动的话。
  4. 空态见 03b：一句结论 + 为什么空 + 回列表动作，不放插画。

顶部导航的未读数是同一份数据：角标数字 + aria-label「通知，2 条未读」；为 0 时角标不渲染，避免 0 这个噪音。
